# 成本会计学Python计算器
> 参考资料：《成本会计学》第10版，于富生、黎来芳、张敏主编
> 适配课程：会计专业《成本会计学》课程，项目功能参考课程教学大纲的学习目标

## 项目简介
本项目是面向会计专业学生开发的交互式成本核算Python学习工具，依据成本会计通用核算原理开发，计算规则参考《成本会计学》（第10版）中的核算方法，覆盖本科成本会计课程核心计算题型。
可以自动完成各类成本费用归集、分配计算，输出分步解题过程、会计分录、费用分配表与产品成本计算单；附带成本可视化图表，计算结果支持导出CSV文件，方便课后习题验算、课程大作业使用。
项目同时提供**Streamlit 本地图形界面**（`app.py`），左侧章节导航、首页模块卡片、参数表单、结果 KPI、完整解题步骤、计算表、图表和 CSV 下载，和财务管理计算器采用同一种网页应用形态。

本项目为学生自主开发的学习工具，仅用于成本会计课程学习与习题验算，**不是出版社官方配套软件**。项目内所有案例均为自行设计的模拟教学案例，不摘抄任何教材原文、原题或图片。

## 课程大纲覆盖章节
1. 第一章 成本会计总论：成本含义、分类、成本会计职能、核算程序
2. 第二章 要素费用的归集与分配：材料、外购动力、职工薪酬、其他费用分配
3. 第三章 辅助生产费用的归集与分配：直接分配法、交互分配法、计划成本分配法、代数分配法
4. 第四章 制造费用、生产损失、期间费用归集分配：制造费用分配、废品损失、停工损失、期间费用结转
5. 第五章 生产费用在完工产品与在产品之间归集分配：约当产量法、定额比例法等6种分配方法
6. 第六章 产品成本计算——品种法，完整核算流程
7. 第七章 产品成本计算——分批法（含简化分批法）
8. 第八章 产品成本计算——分步法：逐步结转（含成本还原）、平行结转分步法
9. 第九章 产品成本计算方法拓展：分类法、联产品与副产品成本核算
10. 第十章 成本报表编制与成本分析：成本报表、可比产品成本分析

## 环境依赖
需要安装 Python 以及以下第三方库：

- Python 3.9 及以上（已在 Python 3.14.7 环境测试）
- pandas 2.0 及以上
- matplotlib 3.8 及以上（成本饼图、结构分析图、差异对比图）
- streamlit 1.57 及以上（本地网页图形界面）

安装命令：

```bash
python -m pip install -r requirements.txt
```

说明：辅助生产费用代数分配法使用项目内置的高斯消元法求解线性方程组，不依赖 sympy。

## 安装与运行

1. 将项目文件夹下载或复制到本地，例如桌面；
2. 打开命令行，进入项目目录：

```bash
cd 桌面/cost-accounting-calculator
```

3. 安装依赖：

```bash
python -m pip install -r requirements.txt
```

4. 启动图形界面：

```bash
python -m streamlit run app.py
```

5. 浏览器会自动打开 `http://localhost:8501`。关闭启动窗口即可停止本地服务。

原控制台版仍保留，可运行：

```bash
python main.py
```

## 功能特点

- **章节全覆盖**：按课程教学大纲第一章至第十章组织侧边栏导航和首页卡片，覆盖成本会计核心计算题型。
- **网页图形界面**：采用 Streamlit 实现章节导航、参数表单、可编辑表格、KPI 卡片和结果展示，与财务管理计算器同一形态。
- **解题过程完整**：每次计算输出文字题意、公式、分步计算、分配表/成本计算单、会计分录和总结，可直接对照作业核对。
- **参数校验友好**：对负数、零分母、非法字符、空输入、完工数量为 0、定额大于费用总额等情况给出中文提示，页面不会崩溃。
- **自动生成表格**：费用分配表、辅助生产费用分配表、产品成本计算单、成本报表、因素分析表等以页面表格和 CSV 两种形式输出。
- **自动绘图**：成本结构饼图、结构分析图、本期/上期及计划/实际差异对比图自动保存到 `chart` 文件夹，并直接显示在页面中。
- **中文乱码处理**：matplotlib 自动检测微软雅黑、黑体等中文字体，并设置 `axes.unicode_minus=False`，解决中文和负号显示异常。
- **CSV 自动保存**：每次计算保存一份完整明细 CSV，同时向 `output/计算记录汇总.csv` 追加摘要，Excel 可直接打开、筛选和统计。
- **一键示例**：每个章节页都有“运行本页示例”按钮，可快速查看完整计算过程。
- **代码中文注释**：核算函数、输入校验、表格输出和绘图代码均配有详细中文注释，便于阅读和二次修改。

## 使用说明

- 在左侧选择“概览”或第一章至第十章，进入对应章节；
- 每个章节先选择计算类型，再在表单中填写金额、数量或编辑表格；
- 点击“开始计算”生成结果；点击“运行本页示例”可一键查看内置案例；
- 所有金额单位为元，数量单位按题目口径输入；
- 比率按百分数输入，例如 14 表示 14%，-2 表示 -2%；
- 结果区会显示 KPI、题意、公式、步骤、计算表、会计分录和结论；
- 每次计算自动保存 CSV，页面提供“下载本次完整计算书 CSV”按钮；
- 第十章成本结构分析和对比分析会自动生成图表，保存在 `chart` 文件夹并显示在页面中；
- 原控制台版仍可使用：`python main.py`，但推荐使用 Streamlit 图形界面。

## 输出文件说明

### output 文件夹

- 每次计算生成一个独立 CSV，文件名格式为：`章节_计算项目_时间戳.csv`；
- CSV 内部按“文字题意、计算公式、分步计算过程、计算表、会计分录、总结”分节；
- `计算记录汇总.csv` 汇总每次计算的章节、项目、主要结论和明细文件名，便于在 Excel 中筛选和统计；
- 所有 CSV 使用 `utf-8-sig` 编码，Windows 下用 Excel 双击打开不会出现中文乱码。

### chart 文件夹

- 成本结构饼图：显示各成本项目占比；
- 成本项目结构分析图：按金额排序并标注占比；
- 差异对比图：本期/上期、计划/实际、上年/本年等分组柱状对比；
- 第十章的报表、可比产品、单位成本和结构分析会自动生成图表；
- 图片格式为 PNG，文件名包含图表名称和时间戳，不会覆盖旧图。

## 计算口径与假设

1. 材料费用分配中，定额消耗量法按“产量 × 单位定额消耗量”确定分配标准；定额费用法在此基础上乘以材料计划单价；重量法和产量法分别按重量、产量分配。
2. 辅助生产费用代数分配法使用联立方程求解各辅助车间待分配总成本，再除以劳务总量得到单位成本；对外分配总额应与辅助车间直接费用合计一致。
3. 计划成本分配法按计划单位成本向所有受益对象分配，实际成本包括直接费用和按计划成本从其他辅助车间转入的费用，成本差异转入管理费用。
4. 约当产量法下，原材料一次投入时在产品材料投料程度按 100% 计算；陆续投入时按输入的投料程度折算；人工和制造费用按加工完工程度折算。
5. 逐步结转综合结转法下，半成品成本以“半成品”综合项目结转，最终产成品成本按上一步骤成本结构进行成本还原；成本还原不改变产成品总成本。
6. 逐步结转分项结转法按“上步转入成本按实物数量比例分配、本步加工费按约当产量分配”的教学口径计算，最终产成品保留原始成本项目，一般不需要成本还原。
7. 平行结转分步法下，某步骤约当产量包括最终产成品数量、本步骤在产品约当产量和后续步骤在产品数量；后续步骤在产品对本步骤而言按 100% 计入，形成“广义在产品”。
8. 简化分批法只对已完工批次分配累计间接费用，未分配累计间接费用留在基本生产成本二级账，与未完工批次直接成本共同构成期末在产品成本。
9. 成本分析中的可比产品成本降低额三因素分析，将实际降低额与计划降低额的差异分解为产量变动、品种结构变动和单位成本变动；三因素影响合计应与差异总额一致。
10. 所有金额计算保留两位小数；分配过程中出现的尾差调整到最后一个分配对象，以保证分配额合计等于待分配总额。

## 常见问题

**Q1：图表中文显示为方框怎么办？**
程序会自动检测 `Microsoft YaHei`、`SimHei` 等字体，并主动注册 Windows 字体文件。若仍有问题，可在系统中安装微软雅黑/黑体后重新运行，或修改 `visual.py` 中的字体候选列表。

**Q2：CSV 用 Excel 打开乱码怎么办？**
项目使用 `utf-8-sig` 编码写入 CSV。若仍乱码，可在 Excel 中通过“数据 → 从文本/CSV”导入，并选择 UTF-8 编码。

**Q3：输入错了会不会导致页面崩溃？**
程序对数字、负数、除零、空输入、数量为 0 等情况做了统一校验，并给出中文错误提示；Streamlit 页面会捕获异常并显示错误详情。

**Q4：如何用自己的题目数据计算？**
进入对应章节和计算类型后，修改表单中的金额、数量或表格内容，点击“开始计算”即可。默认值仅用于演示，所有计算过程、表格和分录都会根据当前输入重新生成。

**Q5：如何只导出某一张表？**
可在 Python 交互环境中调用 `export.save_table(...)`，或在生成的完整 CSV 中复制对应表格区域。
